# 文策析｜办公文档任务智能拆解与导出工具 v2.3

> 面向会议纪要、工作方案等办公文稿场景的本地文档解析智能体：上传 Word/PDF 文字（或直接粘贴、录音），自动识别时间、责任人、机构场所、任务阶段，输出结构化任务清单，并一键导出 CSV 任务表、ICS 日历文件，快速把非结构化公文转化为可落地的工作计划。
>
> 智能体形成「**文本读取（认知）→ 要素抽取与任务拆解（决策）→ 结构化清单/日历导出（执行）**」完整闭环，并在导出前做规划、人工确认与产物自检。
>
> **核心能力 100% 本地运行，无需联网、无需注册、无需 API 密钥，数据不出电脑。**
>
> 参赛信息：智能体创意作品赛 · 智能体赛道 · 队伍「数牍工坊」· GitHub 开源。

## 一、快速开始（双击即可）

1. 打开项目文件夹；
2. 双击 `启动项目.bat`；
3. 浏览器会自动打开 `http://localhost:5173`（端口被占用时自动顺延）。

- 已安装 Node.js（推荐 18 及以上）：启动本地服务，功能完整——支持 **Word（.docx）上传解析**、智能体产物下载；
- 未安装 Node.js：脚本自动改用**静态模式**打开页面，粘贴/录音/分析/导出可用（Word 解析需服务模式）；
- Node.js 免费下载：<https://nodejs.org/zh-cn>（LTS 版，一路下一步即可）。

命令行方式：

```bash
npm start        # 启动
npm test         # 45 项自动化测试（引擎/工具/Word 解析/评测断言）
npm run eval     # 仅跑中文办公语料评测集（16 个标注用例）
```

## 二、核心能力

| 模块 | 说明 |
| --- | --- |
| **Word 文档上传** | 直接上传 **.docx 会议纪要/工作方案/任务通知**（≤10MB），本地零依赖解析为文本（旧版 .doc 请先在 Word 里另存为 .docx）；另支持 .txt/.md/.csv/.log 与直接粘贴 |
| 关键信息抽取 | 轻量规则引擎自动识别任务内容、责任人、截止时间（含"本周四""月底"、英文 Friday 等相对日期）、时间点、金额、电话、邮箱、机构、人物、地点 |
| 结构化任务清单 | 输出任务表，含责任人/优先级/截止时间/**置信度与原文出处**，支持行内增删改，可勾选跟踪进度 |
| 多格式导出 | **CSV 任务表**（带 BOM，Excel/飞书/钉钉直接打开）、**ICS 日历文件**（手机/Outlook/飞书日历可导入，含提醒与时区）、工作报告/核对清单/JSON |
| 智能体执行 | 确定性规划动作 → 用户逐条勾选确认 → 顺序执行 → 每个产物自检 → 交付；未勾选记"跳过"、失败记"失败"，不冒充成功 |
| 数据看板 | 纯 SVG 零依赖图表：完成进度环、优先级/置信度分布、问题构成、责任人/阶段分布、**截止时间线**（逾期红点），随任务勾选实时联动 |
| 矛盾与遗漏检查 | 金额/数据冲突、报价 vs 合同口径、状态矛盾、时间变更、要素缺失、重复内容，逐条附原文依据 |
| 录音纪要 | 浏览器本地录音（MediaRecorder，可回放/下载）+ 可勾选的中文实时转写（Web Speech），转写文本一键生成纪要 |
| 异常容错 | 解析失败、缺责任人/截止时间、文件格式不符等都有明确提示与降级路径，不伪造结果；历史任务本机保存（最多 50 条） |
| 可选 AI 增强 | 自带 OpenAI 兼容密钥才可启用，发送前二次确认；不配置不影响任何核心功能，失败如实报错 |

## 四、测试与质量

- `npm test`：**45 项**自动化测试（node:test，零依赖），最近一次全部通过。
- `node tests/browser/headless-check.js`：浏览器端到端检查（先在 5188 端口启动服务并开两个远程调试无头 Edge，脚本头部注释有用法），覆盖真实点击、**真实 Word 上传解析**、真实文件下载、数据看板、手机视口与 JS 错误，最近一次 **27 项全部通过**。
- 评测集（16 个手工标注的真实办公语料）最近一次结果：待办召回/精确率、责任人、泛称、日期、人名召回均 100%，假人名 0、问题漏检 0；单篇平均约 2.45 ms。**评测样本为自构造语料，不代表任意文本的泛化准确率，详见 `docs/实测报告.md`。**

## 五、技术栈

- 前端：原生 HTML/CSS/JavaScript（无框架、无构建），图表为纯手写 SVG；
- 后端：Node.js 内置 `http` 与 `zlib`（**零第三方依赖，无需 npm install**）；
- 智能体：确定性规划 + 工具注册表 + 产物自检 + 注入式执行器；
- 安全：默认绑定 127.0.0.1、CSP 等安全响应头、路径白名单、上传大小限制、密钥仅存 sessionStorage、外发前二次确认。

## 六、隐私与安全（要点）

- 文档只在本机处理，**不上传云端、不向任何服务器发送正文**（Word 也由本地 Node 服务解析，不落地保存）；
- 录音文件不自动上传；实时转写为可勾选项，部分浏览器可能经浏览器厂商服务器处理，不勾选则仅本地录音；
- 历史记录存 localStorage；可选 API 密钥仅存 sessionStorage（关闭标签页即清除）；
- 任何对外发送（AI 增强）前必须弹窗确认；派任务消息只复制、不自动发送；
- MobileClaw 通道未接入，界面如实显示"未连接"，不模拟任何手机操作。

## 七、当前限制（诚实声明）

1. Word 解析支持标准 .docx；旧版 .doc（二进制）与 PDF 暂不支持，建议先另存为 .docx（PDF 可复制文本后粘贴）；
2. MobileClaw 手机通道未接入（缺官方 SDK/文档），手机端用 .ics 导入、CSV 导入、消息复制人工发送作为真实替代；
3. AI 增强未用真实密钥做线上实测，调用失败会如实报错；
4. 评测集为 16 个自构造中文办公语料，无第三方标注；
5. 无头浏览器中剪贴板读取被环境拒绝（写入有 execCommand 兜底），真人浏览器正常。

详见 `docs/当前限制与MobileClaw接入说明.md`。
