# 智办通 AI 智能办公助手 v2.0

> 中文 AI 办公自动化平台：粘贴一份会议纪要 / 通知 / 计划 / 合同，系统先**分析提取**，再**规划任务、逐条执行、自检产物、交付成果**。
>
> v2 已从"分析工具"升级为**可执行的本地智能体**：规划 → 人工确认 → 工具执行 → 产物自检 → 交付，并保留一条诚实的 MobileClaw 接入通道（未连接时明确告知，不模拟、不伪造）。
>
> **核心能力 100% 本地运行，无需联网、无需注册、无需 API 密钥，数据不出电脑。**

---

## 一、快速开始（双击即可）

1. 打开项目文件夹；
2. 双击 `启动项目.bat`；
3. 浏览器会自动打开 `http://localhost:5173`（端口被占用时自动顺延）。

- 已安装 Node.js（推荐 18 及以上）：启动本地服务，功能完整，智能体可下载真实产物文件。
- 未安装 Node.js：脚本会自动改用**静态模式**直接打开页面，分析、待办、历史、导出等功能可用，但通过本地服务下载产物的体验以服务模式为准。
- Node.js 免费下载：<https://nodejs.org/zh-cn>（LTS 版，一路下一步即可）。

命令行方式：

```bash
npm start        # 启动
npm test         # 36 项单元/评测测试（engine 18 + tools 10 + 评测断言 8）
npm run eval     # 仅跑中文办公语料评测集（16 个标注用例）
```

## 二、v2 核心能力

| 模块 | 说明 |
| --- | --- |
| 文本材料分析 | 字数/句数/段落/阅读时长、关键词、抽取式摘要、文档分类、情感倾向 |
| 关键信息提取 | 日期（含"本周四""月底"、英文 Friday 等相对日期）、时间点、电话、邮箱、金额、百分比、机构、人物、地点、截止时间 |
| 自动待办清单 | 识别行动事项，解析责任人（多责任人/部门+人名/英文祈使）、优先级、截止时间、**置信度与原文出处**；支持行内增删改 |
| 智能体执行（v2 新增） | **确定性规划动作 → 用户逐条勾选确认 → 顺序执行 → 每个产物自检 → 交付**；未勾选动作记为"跳过"，自检失败记为"失败"，不冒充成功 |
| 真实工具产物（v2 新增） | 任务日历 `.ics`（手机/Outlook/飞书日历可直接导入，含提醒）、待办清单 `.csv`（飞书/钉钉/Excel 可导入，带 BOM）、执行核对清单 `.md`、工作报告 `.md`、结构化结果 `.json`、**按责任人分组的派任务消息**（复制到微信/飞书/钉钉由本人确认发送） |
| 任务计划 | 工作日自动排期、四阶段划分、关键里程碑、过期告警 |
| 工作报告 | 七章节规范 Markdown 报告（含置信度标注） |
| 矛盾与遗漏检查 | 金额/数据冲突、报价 vs 合同口径提示、状态矛盾、时间变更、信息缺失、重复内容，逐条附原文依据 |
| 执行进度 | 勾选完成、进度条实时更新、计划/报告/智能体联动重算 |
| 历史任务 | 浏览器本地保存（最多 50 条），可载入/删除/导出 |
| 结果导出 | Markdown、TXT、JSON，以及智能体生成的全部文件 |
| 可选 AI 增强 | 自带 OpenAI 兼容密钥才可启用；**发送前必须二次确认**；不配置不影响任何核心功能，失败如实报错，绝不伪造 |

## 四、测试与质量

- `npm test`：36 项自动化测试（node:test，零依赖）。
- `node tests/browser/headless-check.js`：浏览器端到端检查（需要先在 5188 端口启动服务并开两个远程调试无头 Edge，脚本头部注释有用法），覆盖真实点击、真实下载、手机视口与 JS 错误，最近一次 21 项全部通过。
- 评测集（16 个手工标注的真实办公语料，含会议纪要、通知、迭代计划、采购合同、故障复盘、报销、口语、疑问等）最近一次结果：待办召回/精确率、责任人、泛称、日期、人名召回均 100%，假人名 0、问题漏检 0；单篇平均约 2.39 ms。**评测样本为自构造语料，不代表任意文本的泛化准确率，详见 `docs/实测报告.md`。**

## 五、技术栈

- 前端：原生 HTML/CSS/JavaScript（无框架、无构建步骤）；
- 后端：Node.js 内置 `http`（**零第三方依赖，无需 npm install**）；
- 智能体：确定性规划 + 工具注册表 + 产物自检 + 注入式执行器（浏览器/Node 可替换）；
- 安全：默认绑定 127.0.0.1、CSP 等安全响应头、路径白名单、密钥仅存 sessionStorage、外发前二次确认。

## 六、隐私与安全（要点）

- 材料默认只在本机处理，**不向任何服务器发送文本**；
- 历史记录存 localStorage；可选的 API 密钥保存在 sessionStorage（关闭标签页即清除，首次打开会把旧的 localStorage 密钥迁移并删除）；
- 任何对外发送（AI 增强）前必须弹窗确认目标地址与发送范围；
- 派任务消息**只复制、不自动发送**，系统不会替用户对外发消息；
- MobileClaw 通道未接入，界面如实显示"未连接"，不模拟任何手机操作。

## 七、当前限制（诚实声明）

1. MobileClaw 手机通道**未接入**（缺官方 SDK/文档），手机端用 `.ics` 导入、CSV 导入、消息复制人工发送作为真实替代；
2. AI 增强未用真实密钥做线上实测，调用失败会如实报错；
3. 评测集为 16 个自构造中文办公语料，无第三方标注；
4. 无头浏览器中剪贴板读取被环境拒绝（写入有 execCommand 兜底），真人浏览器正常。

详见 `docs/当前限制与MobileClaw接入说明.md`。
