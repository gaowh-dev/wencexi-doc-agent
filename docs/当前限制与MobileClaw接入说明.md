# 当前限制与 MobileClaw 接入说明

> 本文件如实记录项目当前的能力边界、未实现项及后续接入计划，不夸大、不伪造。

---

## 一、当前限制

### 1. MobileClaw 手机通道未接入（最高优先级缺口）

- 项目已预留适配层 `src/core/adapters/mobileclaw.js`，但**未接入官方 SDK / 能力文档**；
- 当前没有任何真实手机操作能力（建日历事件、发消息、建提醒均不存在）；
- 适配层显式返回 `MOBILECLAW_NOT_CONNECTED`，界面如实显示“未连接”，调用必抛错——**不模拟、不伪造**。
- 当前真实替代方案：
  - 任务日历 `.ics`：手机日历/Outlook/飞书可直接导入（含提醒、VTIMEZONE）；
  - 待办 `.csv`：飞书/钉钉/Excel 可导入（带 BOM、含任务阶段）；
  - 派任务消息：按责任人分组，复制后由本人确认发送。

### 2. 可选 AI 增强

- 支持 OpenAI 兼容接口，但未用真实密钥做端到端实测；发送前强制二次确认，不配置不影响核心功能，调用失败如实报错。

### 3. 评测与准确率

- 16 个语料为**自构造中文办公文本，无第三方标注**；100% 结果不代表任意真实文本的泛化准确率。

### 4. 文件与输入

- 上传仅支持 `.txt/.md`，固定按 UTF-8 解码；GBK 文本预计乱码；不支持 docx/pdf。
- 上传大小上限 5MB。

### 5. 其他

- 无头浏览器中剪贴板读取被环境拒绝（写入有 execCommand 兜底，真人浏览器正常）；
- `.ics` 已补 VTIMEZONE，但未做真机导入全量验证；
- 历史记录的载入/导出/删除 E2E 未覆盖；
- 控制台中文显示在真实 cmd 窗口实测正常（Node 经 WriteConsoleW 输出）。

## 二、MobileClaw 接入计划（与 mobileclaw.js 注释一致）

待官方赛题 / SDK / 接口文档明确后，按以下步骤实现，复用现有智能体框架，不推翻现有设计：

1. **授权连接**：实现 `MobileClaw.connect({ token / device })`，确认授权方式与设备绑定；
2. **三个核心动作**：
   - `calendar.create`：在手机日历创建任务事件（含提醒）；
   - `message.send`：经用户确认后向指定责任人发送任务消息；
   - `reminder.create`：在手机上创建到期提醒；
3. **注册工具**：在 `src/core/agent.js` 的工具注册表中增加 `mobileclaw_*` 工具，复用 **plan → 逐条确认 → 执行 → verify** 的既有流程；
4. **安全约束**：
   - 所有手机动作必须保留用户逐条确认与执行日志；
   - 禁止未经确认直接操作手机；
   - 失败必须如实记录，不得回退为模拟成功。
5. **验证**：补齐对应单元测试与真机端到端检查，记录真实执行结果。

## 三、需要的外部输入

- MobileClaw 官方赛题说明、SDK / 接口文档、授权方式与可调用动作清单。
- 拿到上述资料前，真机通道无法开始实现（避免凭空猜测接口）。
