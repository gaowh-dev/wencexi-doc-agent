# 智办通 AI 智能办公助手 · 项目介绍

## 一、项目背景

在日常工作中，职场人每天要处理大量中文办公材料：会议纪要、通知公告、项目计划、工作报告、合同邮件等。这些材料往往篇幅长、信息散、待办多、时间紧，人工阅读和整理存在三个痛点：

1. **读得慢**：一份几千字的材料，通读、划重点、找关键信息耗时耗力；
2. **容易漏**：谁负责、什么时间前完成、在哪里开会，漏看一条就可能延误工作；
3. **难沉淀**：材料看完就散落在聊天记录和邮箱里，待办、计划、报告无法自动沉淀为可执行的工作成果。

市面上的大模型产品虽然强大，但存在数据上云、需要付费、没有网络就不能用、针对办公场景的结构化能力（排期、矛盾检查、进度跟踪）不足等问题。

**智办通**旨在用一套可离线运行的中文办公分析引擎，让每个人都能一键把"材料"变成"行动"。

## 二、项目定位

- **一句话定位**：把任意中文办公材料，一键变成"摘要 + 待办 + 计划 + 报告 + 检查结果"的个人 AI 办公助手。
- **目标用户**：行政、项目经理、产品、研发、运营、财务、学生干部等所有需要处理文字材料的人群。
- **使用门槛**：零编程基础，双击 `启动项目.bat` 即可使用；无需注册、无需密钥、无需联网。

## 三、核心功能一览

| 编号 | 功能 | 输入 | 输出 |
| --- | --- | --- | --- |
| F1 | 文本材料分析 | 原始文本 | 统计指标、关键词、摘要、分类、情感倾向 |
| F2 | 关键信息提取 | 原始文本 | 日期/时间/电话/邮箱/金额/机构/人物/地点/截止时间 |
| F3 | 自动待办清单 | 原始文本 | 含责任人、优先级、截止时间的待办列表 |
| F4 | 任务计划制定 | 待办列表 | 工作日排期、四阶段计划、里程碑 |
| F5 | 工作报告生成 | 全部分析结果 | 七章节规范 Markdown 报告 |
| F6 | 矛盾与遗漏检查 | 原始文本 + 待办 | 矛盾/遗漏/重复/建议清单（含严重级别与依据） |
| F7 | 执行进度展示 | 勾选状态 | 完成率进度条 |
| F8 | 历史任务保存 | 分析结果 | 本机历史列表，可载入/删除/导出 |
| F9 | 处理结果导出 | 全部结果 | Markdown / TXT / JSON |
| F10 | 可选大模型增强 | 自配 API | 更自然的报告文本（失败明确报错，不伪造） |

## 四、典型使用场景

1. **会议纪要**：会议结束后粘贴纪要，自动抽出"谁、在什么时间前、完成什么"，生成周计划与任务报告；
2. **通知公告**：检查通知里是否漏写了会议时间、地点、参会范围；
3. **项目计划**：把带日期的任务自动排到工作日，识别关键里程碑；
4. **合同/采购邮件**：抽取金额、供应商、付款截止日，发现同一预算前后金额不一致的问题；
5. **工作报告**：自动生成结构完整的周报/月报初稿，人工只需微调。

## 五、项目亮点

1. **真·离线可用**：核心引擎为自研规则算法，不依赖任何外部服务，断网可用、数据不出本机；
2. **零依赖、零安装**：无需 `npm install`，双击即可运行，不污染系统环境；
3. **面向办公场景的结构化输出**：不止于"聊天"，而是直接产出待办、排期、里程碑、报告、检查结论；
4. **可解释、可追溯**：每一条检查结论都附原文依据，不做黑盒判断；
5. **诚实的 AI 边界**：没有密钥时明确使用本地引擎，密钥调用失败时明确报错，绝不伪造接口结果。
