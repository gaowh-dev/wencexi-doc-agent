# 文策析｜办公文档任务智能拆解与导出工具 · 项目介绍

## 一、参赛基本信息

- 项目名称：**文策析｜办公文档任务智能拆解与导出工具**
- 竞赛赛道：智能体创意作品赛 · 智能体赛道
- 队伍名称：**数牍工坊**
- 作品形态：本地 Web 智能体应用（网页 + 本地 Node 服务，零第三方依赖），源码开源托管于 GitHub

## 二、项目概述（300 字版，与提交的项目计划书一致）

日常办公中会议纪要、工作文档内的任务信息零散杂乱，人工提取任务、梳理时间节点、整理责任人耗时费力，容易出现遗漏。本项目是一款本地 Web 智能体应用，面向职场办公人员，自动解析办公文档文本，识别任务内容、责任人、截止时间等关键要素，将非结构化文本转化为结构化任务清单。系统支持一键导出 CSV 任务表、ICS 日历文件，可直接导入日历软件与表格工具。项目采用轻量文本规则抽取技术，无需云端大模型，本地运行保护文档隐私，降低部署成本，解决文档任务信息提取效率低、整理繁琐的痛点，快速完成任务拆解与日程同步。

## 三、项目背景与痛点

- 会议纪要、工作安排、任务通知等公文**篇幅长、信息散、待办多、时间紧**，人工摘抄"谁、在什么时间前、做什么"耗时费力；
- 责任人、截止时间、会议地点**漏看一条就可能延误工作**；
- 通用大模型需要联网、付费且涉及文档上云，政企/保密场景难落地，且不直接产出可导入日历/表格的结构化文件。

文策析构建文档解析智能体，形成「**文本读取（认知）→ 要素抽取与任务拆解（决策）→ 结构化清单/日历导出（执行）**」完整闭环。

## 四、核心技术与亮点

1. **轻量文本要素抽取技术**：从文档中自动识别任务、负责人、截止时间、机构场所、任务阶段，不依赖重型大模型，单篇处理约 2.4 毫秒；
2. **本地 Web 架构**：全部计算本地执行，文档不上传云端，保障企业办公文档数据隐私安全；默认绑定 127.0.0.1，配合 CSP 等安全头；
3. **多格式文件导出**：一键导出 CSV 任务清单（带 BOM，Excel/飞书/钉钉可打开）、ICS 日历文件（含提醒与时区，手机/Outlook/飞书日历可导入）；
4. **Word 文档直接上传**：零依赖解析标准 .docx（Node 内置 zlib 解 ZIP），上传即解析；
5. **简易交互界面**：网页可视化操作，上传文档即可查看解析结果，另配可视化看板与录音纪要，上手门槛低；
6. **智能体闭环与容错**：规划→逐条勾选确认→执行→产物自检→交付，失败/跳过如实记录，信息缺口主动提示。

## 五、功能清单

| 编号 | 功能 | 输入 | 输出 |
| --- | --- | --- | --- |
| F1 | Word/文本读取 | .docx / .txt / .md / .csv / .log / 粘贴文本 / 录音转写 | 规范化正文 |
| F2 | 关键信息抽取 | 正文 | 日期/时间/责任人/金额/电话/邮箱/机构/人物/地点/截止时间 |
| F3 | 结构化任务清单 | 正文 | 含责任人、优先级、截止时间、置信度、原文出处的任务表（可增删改） |
| F4 | 任务计划制定 | 任务清单 | 工作日排期、四阶段计划、里程碑 |
| F5 | 多格式导出 | 全部结果 | **CSV 任务表、ICS 日历文件**、工作报告、核对清单、JSON |
| F6 | 矛盾与遗漏检查 | 正文 + 任务 | 矛盾/遗漏/重复/建议（附原文依据） |
| F7 | 数据看板与进度 | 勾选状态 | 进度环、分布图、截止时间线、完成率 |
| F8 | 历史与容错 | 分析结果 | 本机历史、明确错误提示与降级路径 |

## 六、预期成果

一套本地 Web 智能体应用（源码），配套项目说明文档、演示录屏视频；可实现办公文档上传、任务智能解析、结构化任务展示，支持 CSV、ICS 文件导出；源码开源托管于 GitHub，可直接本地部署运行。

## 七、应用场景与目标对象

- **目标对象**：企事业单位行政、项目管理人员、团队负责人、学生项目小组。
- **典型场景**：项目会议纪要、工作安排文档、任务通知文档处理；快速从长篇文字中提取待办任务，批量整理任务清单并同步到个人日历，省去人工摘抄整理任务的重复工作。

## 八、与普通聊天机器人的区别

- 输入是**真实文档**，输出是**可导入的结构化文件**（CSV/ICS），而非一段对话文字；
- 抽取结果带**置信度和原文出处**，可逐条核对；
- 确定性规则**可复现、毫秒级、断网可用**，不按字数付费；
- 每个导出产物经过**自检**，导出前由用户确认，不替用户对外发送任何信息。
