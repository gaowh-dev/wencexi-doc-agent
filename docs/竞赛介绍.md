# 竞赛项目介绍：文策析｜办公文档任务智能拆解与导出工具

## 一、参赛信息

- 作品名称：**文策析｜办公文档任务智能拆解与导出工具**
- 竞赛赛道：智能体创意作品赛 · 智能体赛道
- 队伍名称：**数牍工坊**
- 作品形态：100% 本地运行的文档解析智能体（网页 + 本地 Node 服务，零第三方依赖），源码开源托管于 GitHub
- 一句话定位：面向会议纪要、工作方案、任务通知等办公文稿，构建「文本读取（认知）→ 要素抽取与任务拆解（决策）→ 结构化清单/日历导出（执行）」完整闭环。

## 二、要解决的真实问题

办公场景中，行政、项目管理人员和团队负责人每天面对大量中文公文，但从"读到材料"到"把事办完"之间存在重复人工劳动：

1. 从大段文字里手工找待办、责任人、截止时间，容易遗漏；
2. 手工整理任务清单、排日程、写工作报告；
3. 核对金额口径、信息遗漏与矛盾；
4. 把任务一条条转述/派发给责任人。

文策析用一个确定性本地智能体完成上述闭环，**无需联网、无需注册、无需 API 密钥，数据不出电脑**。

## 三、核心能力

| 模块 | 说明 |
| --- | --- |
| Word 文档上传 | 直接上传标准 .docx（≤10MB），本地零依赖解析为文本；另支持 .txt/.md/.csv/.log 与粘贴、录音 |
| 录音纪要 | 浏览器原生录音 + 中文实时转写（可勾选，明示隐私边界）+ 一键生成纪要 |
| 文本分析 | 字数/句数/段落/阅读时长、关键词、抽取式摘要、文档分类、情感倾向 |
| 关键信息提取 | 相对日期（本周四/月底、英文 Friday）、时间、电话、邮箱、金额（含万亿元）、百分比、机构（含部门）、人物、地点、截止时间 |
| 结构化任务清单 | 解析责任人/优先级/截止时间/**置信度与原文出处**，支持行内增删改 |
| 智能体执行 | 规划动作 → 用户逐条勾选确认 → 顺序执行 → 每个产物自检 → 交付；未勾选记"跳过"、失败记"失败"，不冒充成功 |
| 多格式导出 | **CSV 任务表（带 BOM）、ICS 日历（含 VTIMEZONE/提醒）**、核对清单、工作报告、JSON、按责任人分组的派任务消息 |
| 数据看板 | 纯 SVG 零依赖图表：完成进度环、优先级/置信度分布、问题构成、责任人/阶段分布、截止时间线（逾期红点） |
| 矛盾遗漏检查 | 金额冲突、口径提示、状态矛盾、时间变更、信息缺失、重复内容，逐条附原文依据 |
| 异常容错 | 格式不符/缺要素/解析失败均有明确提示与降级路径，不伪造结果 |
| 安全合规 | 仅绑定 127.0.0.1、CSP 等五项安全头、路径白名单、上传大小限制、密钥仅存 sessionStorage、外发前二次确认 |

## 四、创新点

1. **非结构化公文→可执行成果的闭环**：不停留在"分析文本"，而是直接产出可导入日历/表格的 CSV/ICS 文件，全部确定性可复现；
2. **真·离线隐私优先**：自研轻量规则引擎（单篇约 2.4 毫秒），文档不上云、无第三方依赖、无构建步骤，适合政企/保密场景；
3. **产物级自检 + 诚实边界**：每个交付文件生成后 verify 自检，失败如实记录；MobileClaw 真机通道未接入时显式声明"未连接"，不模拟、不伪造；
4. **可视化与可追溯**：每条任务带置信度与原文出处，看板实时呈现全局，金额口径冲突等问题附原文依据。

## 五、技术栈

- 前端：原生 HTML/CSS/JavaScript（无框架、无构建，图表为纯手写 SVG）；
- 后端：Node.js 内置 `http` 与 `zlib`（Word 解包），零第三方依赖；
- 智能体：确定性规划 + 工具注册表 + 注入式执行器 + 产物自检；
- 测试：node:test（45 项）、自研 CDP 端到端检查（27 项，含**真实 Word 上传解析**与真实文件下载）、16 个中文标注语料评测。

## 六、实测概况

- 45 项自动化测试全部通过；27 项浏览器端到端断言全部通过；
- 16 个标注语料：待办召回/精确率、责任人、泛称、日期、人名召回均 100%，假人名 0；
- 单篇平均处理约 2.45 ms；
- 按官方五维评分框架的保守自评为 **82/100**（初版 57），详见 `docs/参赛达标检查.md`。

## 七、当前限制（诚实声明）

1. Word 解析支持标准 .docx；旧版 .doc 与 PDF 暂不支持（建议另存为 .docx 或粘贴文本）；
2. MobileClaw 真机通道未接入（待官方 SDK/文档），以本地文件导入与人工复制为替代；
3. 可选 AI 增强未用真实密钥做线上实测；
4. 评测语料为自构造，不代表任意文本泛化结果。

详见 `docs/当前限制与MobileClaw接入说明.md`。
