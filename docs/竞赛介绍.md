# 竞赛项目介绍：智办通 AI 智能办公助手

## 一、参赛信息

- 作品名称：智办通 AI 智能办公助手
- 参赛赛道：MobileClaw 智能体赛道
- 作品形态：100% 本地运行的中文办公智能体（网页 + 本地 Node 服务，零第三方依赖）
- 一句话定位：粘贴一份会议纪要 / 通知 / 计划 / 合同，系统先分析提取，再**规划任务、逐条确认、真实执行、自检产物、交付成果**。

## 二、要解决的真实问题

办公场景中，管理者和项目成员每天面对大量中文文字材料（会议纪要、通知、计划、合同），但从“读到材料”到“把事办完”之间存在重复人工劳动：

1. 从大段文字里手工找待办、责任人、截止时间；
2. 手工整理待办清单、排日程、写工作报告；
3. 核对金额口径、信息遗漏与矛盾；
4. 把任务一条条转述/派发给责任人。

智办通用一个确定性本地智能体完成上述闭环，核心能力**无需联网、无需注册、无需 API 密钥，数据不出电脑**。

## 三、核心能力

| 模块 | 说明 |
| --- | --- |
| 文本分析 | 字数/句数/段落/阅读时长、关键词、抽取式摘要、文档分类、情感倾向 |
| 关键信息提取 | 相对日期（本周四/月底、英文 Friday）、时间、电话、邮箱、金额（含万亿元）、百分比、机构（含部门）、人物、地点、截止时间 |
| 待办清单 | 自动识别行动事项，解析责任人/优先级/截止时间/**置信度与原文出处**，支持行内增删改 |
| 智能体执行 | 规划动作 → 用户逐条勾选确认 → 顺序执行 → 每个产物自检 → 交付；未勾选记“跳过”、失败记“失败”，不冒充成功 |
| 真实产物 | 任务日历 `.ics`（含 VTIMEZONE/提醒）、待办 `.csv`（带 BOM、含任务阶段）、核对清单 `.md`、工作报告 `.md`、结构化 `.json`、按责任人分组的派任务消息 |
| 任务计划 | 工作日自动排期、四阶段划分、里程碑、过期告警 |
| 矛盾遗漏检查 | 金额冲突、口径提示、状态矛盾、时间变更、信息缺失、重复内容，逐条附原文依据 |
| 安全合规 | 仅绑定 127.0.0.1、CSP 等五项安全头、路径白名单、密钥仅存 sessionStorage、外发前二次确认 |

## 四、创新点

1. **可执行的本地智能体**：不停留在“分析文本”，而是把材料转成可确认、可执行、可自检、可交付的任务闭环，全部确定性可复现。
2. **诚实的通道设计**：MobileClaw 真机通道未接入时显式声明“未连接”，适配层必抛错，**不模拟、不伪造执行结果**；以 `.ics`/CSV/消息复制作为真实可执行替代。
3. **产物级自检**：每个交付文件（ICS/CSV/MD/JSON）生成后都有 verify 检查，自检失败如实记为失败。
4. **隐私优先**：核心能力完全离线，材料不离开本机；无第三方依赖、无构建步骤。

## 五、技术栈

- 前端：原生 HTML/CSS/JavaScript（无框架、无构建）；
- 后端：Node.js 内置 `http`，零第三方依赖；
- 智能体：确定性规划 + 工具注册表 + 注入式执行器 + 产物自检；
- 测试：node:test（36 项）、自研 CDP 端到端检查（21 项）、16 个中文标注语料评测。

## 六、实测概况

- 36 项自动化测试全部通过；21 项浏览器端到端断言全部通过；
- 16 个标注语料：待办召回/精确率、责任人、泛称、日期、人名召回均 100%，假人名 0；
- 单篇平均处理约 2.34 ms。
- 详见 `docs/实测报告.md`。

## 七、当前限制（诚实声明）

1. MobileClaw 真机通道未接入（待官方 SDK/文档），以本地文件导入与人工复制为替代；
2. 可选 AI 增强未用真实密钥做线上实测；
3. 评测语料为自构造，不代表任意文本泛化结果。

详见 `docs/当前限制与MobileClaw接入说明.md`。
