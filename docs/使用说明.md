# 智办通 AI 智能办公助手 · 使用说明

## 一、启动方式

### 方式一：双击启动（推荐）

双击项目根目录的 **`启动项目.bat`**：

- 脚本会自动检查 Node.js 环境；
- 有 Node.js：自动启动本地服务并打开浏览器；
- 没有 Node.js：自动以静态模式打开页面，核心功能照常用。

### 方式二：命令行启动（适合有基础的用户）

```bash
# 进入项目目录
cd 智办通AI智能办公助手
npm start
# 然后浏览器访问 http://localhost:5173
```

### 方式三：直接打开网页

双击 `public/index.html`，即可进入**静态模式**。

> 三种方式的区别：服务模式端口被占用时会自动顺延（5174、5175…）；静态模式地址栏显示 `file://`，功能完全一致。

## 二、操作流程（四步）

**第一步：导入材料**

- 直接在左侧文本框粘贴文字；
- 或点击「加载示例」体验完整演示；
- 或点击「上传文件」读取本地 `.txt / .md / .csv / .log` 文本文件（≤5MB）。

**第二步：一键分析**

点击「② 一键智能分析」，系统会在 1 秒内完成六类分析，并通过顶部标签页呈现：

| 标签页 | 能看到什么 |
| --- | --- |
| 材料分析 | 字数统计、关键词、摘要、文档类型、情感倾向 |
| 关键信息 | 日期、时间、截止时间、金额、电话、邮箱、机构、人物、地点等 |
| 待办与进度 | 待办清单（责任人/优先级/截止时间）与完成进度条 |
| 任务计划 | 四阶段工作日排期表与关键里程碑 |
| 工作报告 | 七章节规范报告（Markdown 排版） |
| 一致性检查 | 矛盾、遗漏、重复、建议，附原文依据 |

**第三步：执行与跟踪**

- 在「待办与进度」中勾选已完成事项，进度条实时更新，报告同步刷新；
- 关注「一致性检查」中的高风险项（红色），优先核实修正。

**第四步：保存与导出**

- 点击「保存到历史」：存入本机浏览器，可随时载入（最多 50 条）；
- 导出格式：
  - **Markdown**：适合直接放进飞书/钉钉文档、语雀、GitHub；
  - **TXT**：适合微信、邮件粘贴；
  - **JSON**：完整结构化数据，供二次开发。

## 三、可选：配置大模型 API（AI 增强）

本系统**不需要任何 API 密钥**即可使用全部核心功能。如希望报告语言更自然，可配置兼容 OpenAI 接口的大模型：

1. 点击右上角「设置」；
2. 填写 **API 地址**（如 `https://api.openai.com/v1` 或其他兼容服务地址）、**API Key**、**模型名称**（如 `gpt-4o-mini`）；
3. 点击「测试连接」验证；
4. 保存后，在结果区点击「✨ AI 增强」。

注意：

- 密钥仅保存在**本机浏览器** localStorage 中，不会被本系统收集；
- 接口未配置、密钥错误或网络不通时，系统会**明确提示错误并继续使用本地引擎**，不会伪造任何回答；
- AI 增强只负责语言润色，关键事实（日期、金额、责任人）以本地引擎提取结果为准。

## 四、材料写作小技巧（识别率更高）

为了让待办、责任人与截止时间识别更准，建议材料中使用规范表述：

- 明确责任人：**"请研发部张伟在 10 月 22 日前完成……"**、**"由李娟负责……"**；
- 明确截止时间：**"请于 10 月 30 日 18:00 前提交"**、**"本周四前"**、**"月底前"**；
- 明确优先级：出现"紧急/务必/立即/马上"会自动标为高优先级；
- 会议通知写全：时间、地点（或线上会议链接）、参会范围。

## 五、常见问题

**Q1：必须联网吗？**
不必须。核心功能完全离线可用。

**Q2：双击 bat 闪退？**
右键 → 用记事本打开，确认文件完整；或在文件夹地址栏输入 `cmd` 回车，再运行 `node src\server.js` 查看报错；也可直接双击 `public/index.html`。

**Q3：换了浏览器，历史记录不见了？**
历史记录保存在所用浏览器的本机存储中，使用同一浏览器打开即可；重要结果请使用「导出」或「保存到历史」。

**Q4：能分析英文或中英混合材料吗？**
当前版本以中文规则为主，英文邮箱、网址、数字信息可正常提取，中文办公场景效果最佳。

**Q5：我的材料会被上传吗？**
不会。未配置自定义 API 时，没有任何网络请求；配置后，请求仅发往你自己填写的接口地址。
