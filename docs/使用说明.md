# 智办通 AI 智能办公助手 · 使用说明

## 一、启动方式

### 方式一：双击启动（推荐）

双击项目根目录的 **`启动项目.bat`**：

- 脚本会自动检查 Node.js 环境；
- 有 Node.js：自动启动本地服务并打开浏览器；
- 没有 Node.js：自动以静态模式打开页面，核心功能照常用。

### 方式二：命令行启动（适合有基础的用户）

```bash
# 进入项目目录
cd 智办通AI智能办公助手
npm start
# 然后浏览器访问 http://localhost:5173
```

### 方式三：直接打开网页

双击 `public/index.html`，即可进入**静态模式**。

> 三种方式的区别：服务模式端口被占用时会自动顺延（5174、5175…）；静态模式地址栏显示 `file://`，功能完全一致。

## 二、操作流程（四步）

**第一步：导入材料**

- 直接在左侧文本框粘贴文字；
- 或点击「加载示例」体验完整演示；
- 或点击「上传文件」读取本地 `.txt / .md / .csv / .log` 文本文件（≤5MB）。

**第二步：一键分析**

点击「② 一键智能分析」，系统会在 1 秒内完成六类分析，并通过顶部标签页呈现：

| 标签页 | 能看到什么 |
| --- | --- |
| 材料分析 | 字数统计、关键词、摘要、文档类型、情感倾向 |
| 关键信息 | 日期、时间、截止时间、金额、电话、邮箱、机构、人物、地点等 |
| 待办与进度 | 待办清单（责任人/优先级/截止时间/置信度/原文出处），可直接行内增删改，完成进度条 |
| 智能体执行 | 动作计划、信息缺口、勾选后真实生成日历/CSV/清单/报告/派任务消息，每步自检 |
| 任务计划 | 四阶段工作日排期表与关键里程碑 |
| 工作报告 | 七章节规范报告（Markdown 排版） |
| 数据看板 | 完成进度环、优先级/置信度分布、责任人/阶段分布、截止时间线（纯 SVG，离线） |
| 一致性检查 | 矛盾、遗漏、重复、建议，附原文依据 |

**第三步：执行与跟踪**

- 在「待办与进度」中勾选已完成事项，进度条实时更新，计划/报告/看板同步刷新；也可直接修改责任人、截止时间、优先级，或手动新增、删除任务；
- 打开「智能体执行」：先查看信息缺口提示并补齐任务要素，然后勾选要执行的动作（建议默认全选），点击「执行选中的动作」；系统会真实生成日历 `.ics`、待办 `.csv`、核对清单、工作报告和按责任人分组的派任务消息，每一步都有自检；
- 派任务消息只复制到剪贴板、由你本人确认后发送，系统不会自动对外发消息；
- 打开「数据看板」查看完成进度、优先级/责任人分布与截止时间线（逾期任务用红点标出）；
- 关注「一致性检查」中的高风险项（红色），优先核实修正。

**第四步：保存与导出**

- 点击「保存到历史」：存入本机浏览器，可随时载入（最多 50 条）；
- 导出格式：
  - **Markdown**：适合直接放进飞书/钉钉文档、语雀、GitHub；
  - **TXT**：适合微信、邮件粘贴；
  - **JSON**：完整结构化数据，供二次开发；
  - **日历 `.ics` / 待办 `.csv`**：在「智能体执行」中生成，可直接导入手机/Outlook/飞书日历与飞书/钉钉表格。

## 二·补、录音纪要（可选）

顶部导航切换到「录音纪要」：

1. 填入会议主题（可选），点击「开始录音」，音频只保存在本机浏览器；
2. 「实时转写」为可勾选选项（Edge/Chrome 提供中文识别，部分浏览器可能经浏览器厂商服务器处理；不勾选则仅本地录音，不影响使用）；
3. 可直接在转写框中核对、修改文字，也支持手动粘贴已有会议记录；
4. 点击「生成会议纪要」，自动跳转工作台，用本地引擎产出摘要、待办、计划、报告并可一键导出。

## 三、可选：配置大模型 API（AI 增强）

本系统**不需要任何 API 密钥**即可使用全部核心功能。如希望报告语言更自然，可配置兼容 OpenAI 接口的大模型：

1. 点击右上角「设置」；
2. 填写 **API 地址**（如 `https://api.openai.com/v1` 或其他兼容服务地址）、**API Key**、**模型名称**（如 `gpt-4o-mini`）；
3. 点击「测试连接」验证；
4. 保存后，在结果区点击「✨ AI 增强」。

注意：

- 密钥仅保存在**本机浏览器的会话存储（sessionStorage）**中，关闭标签页即自动清除，不会随历史任务保存，也不会被本系统收集；
- 接口未配置、密钥错误或网络不通时，系统会**明确提示错误并继续使用本地引擎**，不会伪造任何回答；
- AI 增强只负责语言润色，关键事实（日期、金额、责任人）以本地引擎提取结果为准。

## 四、材料写作小技巧（识别率更高）

为了让待办、责任人与截止时间识别更准，建议材料中使用规范表述：

- 明确责任人：**"请研发部张伟在 10 月 22 日前完成……"**、**"由李娟负责……"**；
- 明确截止时间：**"请于 10 月 30 日 18:00 前提交"**、**"本周四前"**、**"月底前"**；
- 明确优先级：出现"紧急/务必/立即/马上"会自动标为高优先级；
- 会议通知写全：时间、地点（或线上会议链接）、参会范围。

## 五、常见问题

**Q1：必须联网吗？**
不必须。核心功能完全离线可用。

**Q2：双击 bat 闪退？**
右键 → 用记事本打开，确认文件完整；或在文件夹地址栏输入 `cmd` 回车，再运行 `node src\server.js` 查看报错；也可直接双击 `public/index.html`。

**Q3：换了浏览器，历史记录不见了？**
历史记录保存在所用浏览器的本机存储中，使用同一浏览器打开即可；重要结果请使用「导出」或「保存到历史」。

**Q4：能分析英文或中英混合材料吗？**
当前版本以中文规则为主，英文邮箱、网址、数字信息可正常提取，中文办公场景效果最佳。

**Q5：我的材料会被上传吗？**
不会。未配置自定义 API 时，没有任何网络请求；配置后，请求仅发往你自己填写的接口地址。
