设置 · 大模型 API（可选）

不配置 API 密钥时，系统使用内置本地中文分析引擎，所有核心功能均可正常使用。填写兼容 OpenAI 接口格式的大模型后，可使用「✨ AI 增强」获得更自然的报告。密钥仅保存在本浏览器的会话存储（sessionStorage）中，关闭浏览器后自动清除，不会随历史任务保存，也不会上传到任何第三方。

使用帮助

  1. 第一步：在左侧粘贴会议纪要、通知、计划、报告等任意中文办公材料，或点击「加载示例」。
  2. 第二步：点击「一键智能分析」，几秒内得到六大类分析结果，每条待办都带置信度与原文出处。
  3. 第三步：在「待办与进度」页可直接编辑责任人、截止时间、优先级，或手动增删任务；勾选完成事项，进度自动更新。
  4. 第四步：打开「智能体执行」页，先补齐信息缺口，再勾选要执行的动作，系统将真实生成日历文件、CSV、派任务消息、核对清单和报告，每个产物都有自检。
  5. 第五步：点击「保存到历史」长期留存；也可导出 Markdown / TXT / JSON 三种格式。

本地引擎能力：分句、关键词 n-gram 提取、摘要、文档分类、情感倾向、实体抽取（日期/时间/电话/邮箱/金额/百分比/机构/人物/地点/截止时间）、待办识别、工作日排期、矛盾与遗漏检查。

数据外发确认

你即将把当前材料全文和分析结果发送到你自行配置的大模型服务。发送后数据将离开本机，请确认：

  1. 发送目标：（你的 API 地址）；
  2. 发送范围：原始材料全文 + 本地引擎生成的报告；
  3. 材料中不包含身份证、银行卡、商业机密等敏感内容，或你已确认可以发送；
  4. 不配置 API 时，所有核心功能（分析/待办/计划/报告/检查/智能体执行）均在本地完成，不影响使用。
